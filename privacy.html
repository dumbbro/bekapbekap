Kebijakan Privasi bekapbekap

Berlaku sejak 7 November 2026.

Data yang diakses

bekapbekap hanya mengakses file yang dibuatnya sendiri di Google Drive pengguna, melalui izin drive.file. Aplikasi ini tidak membaca file lain di Google Drive.

Cara data digunakan

File cadangan dienkripsi sebelum diunggah, lalu disimpan di Google Drive pengguna. File tersebut hanya digunakan untuk pemulihan data oleh pemiliknya.

Berbagi data

bekapbekap tidak menjual, membagikan, atau mengirim data ke pihak lain, selain menyimpannya di Google Drive pengguna. Data dari Google tidak digunakan untuk iklan atau melatih model AI.

Penghapusan data

Pengguna dapat menghapus file cadangan dari Google Drive kapan saja, dan dapat mencabut akses aplikasi melalui pengaturan akun Google.

Kontak

Pertanyaan dapat diajukan melalui halaman Issues repositori ini.
