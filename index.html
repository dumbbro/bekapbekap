bekapbekap

bekapbekap adalah aplikasi pribadi untuk menyimpan cadangan terenkripsi ke Google Drive milik pemiliknya sendiri.

Aplikasi ini tidak ditujukan untuk umum dan tidak menyediakan layanan bagi pengguna lain.

Penggunaan Google Drive

Aplikasi ini hanya meminta izin drive.file, yaitu akses ke file yang dibuat oleh aplikasi ini. Aplikasi ini tidak membaca file lain di Google Drive.
